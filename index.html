Privacy Policy

Effective Date: September 2026

This Privacy Policy describes how ScienceAutoPost ("we", "us", or "our") manages credentials and information when automating video publishing to connected social media platforms, including YouTube.

1. Information We Access

ScienceAutoPost interacts with the Google YouTube Data API v3 strictly under authorized scopes to upload videos and manage channel metadata on behalf of the channel owner. We do not harvest, store, or sell personal identifying information from third parties.

2. Use of Google User Data

Our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

3. Data Security & Storage

API keys and OAuth tokens are stored encrypted in secure private server environment variables. They are never shared publicly or exposed to third parties.

4. Revoking Access

Users can revoke access at any time via the Google Security Settings page.
